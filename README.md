# Mana Brawl

## How to Host on GitHub Pages

1.  **Upload Files**: Upload all the files in this folder to a GitHub repository.
2.  **Settings**: Go to the repository **Settings**.
3.  **Pages**: On the left sidebar, click **Pages**.
4.  **Source**: Under **Build and deployment**, select **Main** (or **Master**) branch and `/ (root)` folder.
5.  **Save**: Click **Save**.
6.  **Wait**: Wait a minute or two, and GitHub will give you a link to your live game!

## Troubleshooting
-   If the game doesn't load immediately, refresh the page.
-   The game uses relative paths, so it should work automatically.
